# AIKO

AIKO is an interactive birthday experience built with HTML, CSS, and JavaScript.

The project provides a simple password-protected entry screen followed by a
countdown and a collection of interactive birthday screens and visual effects.

## Features

- Password-protected entry screen
- Four-digit password interface
- Birthday countdown timer
- Automatic date-based screen handling
- Interactive screen navigation
- Personalized birthday content
- Background music controls
- Animated transitions and visual effects
- Responsive design for different screen sizes
- Custom images and media

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- CSS Animations
- DOM Manipulation
- Responsive Web Design
